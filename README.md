# 肖瑶的每日阅读

面向手机阅读的独立 HTML 仪表盘，内联样式与脚本，无外部图片、字体或前端库。分为时事、体育、金融、政治、AI、英语学习六个栏目，默认打开时事，不设速览。涵盖 NBA、五大联赛、网球、美股、A股、中国期货、宏观财经、中美政治及原 AI 五版块。

## 在线地址

https://soulyao.github.io/ai-daily-brief/

## 自动更新

- 首页打开、返回前台或点击“检查更新”会读取同源 `latest.json`，额外直连 AI HOT 最新日报。体育、金融和政治由云端采集，手机只读取已发布快照。
- 每天北京时间各偶数小时的第 17 分钟尝试更新，另加 08:47、09:17 晨间重试。平台调度可能延迟，不保证到点发布。
- 时事热搜保留近 24 小时采集结果；体育、金融、政治收录近 72 小时报道，AI 保留最近 14 天内一期。未生成今日版时明确显示最近一期日期。
- 某一来源失败时保留它上次成功的数据及时间（仍遵守时间窗口），在页尾标明；全部来源失败则不覆盖已发布文件，使工作流失败。
- 页面分开显示采集时间、文章发布时间、AI 日报生成时间，均为北京时间。快照超过 6 小时未更新会提示。
- 可在 GitHub Actions 手动运行 `Generate and deploy daily brief`。AI 归档生成暂时失败不会阻止其他新闻发布。

## 路由与内容规则

- `site/index.html`：综合手机版首页，默认时事，支持栏目与子分类筛选。
- `site/latest.json`：刷新使用的数据快照及来源状态。
- `site/ai.html`：保留原 AI 五版块日报与实时检查。
- `site/archive/`：原 AI 日期归档，已有地址保留。

全局连续编号在筛选后保持不变，数字是索引而非热度或评分。摘要取自来源正文或订阅摘录，最长 60 个字符。按主题和发布时间筛选，不对政治人物或政策评分。排除博彩竞猜、索赔广告、港股与私募融资；不填充虚构新闻。同链接、同标题去重，不保证不同标题的同一事件完全合并。

时事从百度热搜公开榜单按关键词筛选，过滤娱乐和赛事，最多展示 6 条，不展示热度分或名次。榜单不提供文章发布时间，因此明确标注“热搜采集”时间；“查看相关新闻”进入百度搜索结果，不冒充原文。关键词筛选不等于人工核验。

## 每日旅游英语

内置 30 个原创旅游情景，按北京时间每天轮换，学完一轮后循环复习。每天一段六句中英文对话、至少三个关键词注释及一个常用句型；支持隐藏中文自测、复习上一课、回到今日课程。课程和脚本均内联，无需请求接口；跨北京时间零点自动切换，返回页面时也会检查日期。对话里的价格、航班和服务规则仅为练习示例。

## 本地生成

金融子类各最多 6 条，为用户指定的东方财富保留最多 2 条可用报道，其余名额按时间选取；展示仍按发布时间排列。东方财富取财经、股票、美股、期货频道中的文章，保留“东方财富 · 原始媒体”署名，使用文章内的真实发布时间，排除自动生成的行情汇总。宏观财经侧重利率、通胀、就业、经济数据和货币财政政策。

金融卡片的“观点”标签用于明确的机构策略、预测、展望及期货投研内容，由标题和摘要规则识别，不表示全面人工审核。抓取异常沿用来源回退机制，仍受 72 小时时间窗口限制。

期货使用东方财富网页公开使用的新闻列表接口（栏目 765），再读取财经域名下的文章原文，避免期货首页在云端偶发连接失败导致更新停滞。宏观栏目合并财经首页与该列表；一个索引不可用时仍可使用另一个成功索引。列表和正文均验证结构、日期、来源及所属主题。

```powershell
node scripts/generate.mjs
node scripts/collect-news.mjs
node --test tests/*.test.mjs
```

Node.js 22 以上，无需安装运行依赖。生成结果位于 `site/`。
